## 袅来运转桌面版 1.5.0

适用于 Windows 10/11 x64。下载 `niaolaiyunzhuan_1.5.0_x64-setup.exe` 安装。

- 玄墨侧栏、宣纸暖金三栏界面，自定义标题栏。
- 按区域、玩法、限时和概率来源记录袅袅之音；支持任务、人物与商店搜索。
- 单项与整组勾选、本地自动保存、周期刷新、活动倒计时。
- PNG 备份导出、NYNZ1/NYNZ2 恢复预览与合并。
- 签名在线更新：启动时检查新版本，在“设置与更新”中下载并安装。
- 更新同时校验安装包签名与签名中的版本号，安装后自动启动程序。

数据沿用网页版 v1.5.0 修订 73，共 128 条来源、207 个独立目标。原作者：薄荷小鹿（燕云十六声）。

`latest.json` 和 `.sig` 用于程序更新；`SHA256SUMS` 用于手动校验下载文件。安装包具有 Tauri 更新签名，Windows Authenticode 发布者证书尚未配置。缺少 WebView2 时，安装器会联网获取运行时。
